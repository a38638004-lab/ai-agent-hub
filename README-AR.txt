AI Agent Hub — النسخة المحسنة

المزايا:
- إدارة المشاريع وإضافة/حذف سجلات الحسابات.
- منع تكرار الحساب نفسه داخل المشروع.
- حفظ البيانات محليًا على الجهاز عبر المتصفح.
- إعدادات محلية للوحة.
- اختبار اتصال API مع Worker عبر HTTPS وBearer token.
- واجهة PWA قابلة للإضافة للشاشة الرئيسية.

تنبيه مهم:
هذه لوحة إدارة أولية وليست منصة نشر آلي مكتملة. لا يوجد OAuth أو نشر فعلي على TikTok/Facebook/Instagram/YouTube، ولا تُخزن كلمات مرور المنصات. نجاح اختبار /api/health لا يعني ربط حسابات التواصل.

النشر:
ارفع ملفات المجلد إلى جذر مستودع GitHub، مع استبدال index.html والملفات المساندة. فعّل GitHub Pages من Settings > Pages > Deploy from a branch > main > /(root). يجب أن يكون المستودع Public على GitHub Free. لا ترفع أسرارًا أو رموز وصول إلى المستودع.


إضافة الأرباح:
- تبويب الأرباح يسجل مبالغ تقديرية/معتمدة/قابلة للسحب/تم استلامها بعملتي USD وEGP.
- هذه سجلات متابعة وليست اتصالًا مباشرًا بواجهات أرباح المنصات. يلزم استيراد تقرير رسمي أو تكامل API معتمد للتحقق من الأرقام.
- وسيلة البنك أو PayPal تسجل كطريقة متابعة؛ إعداد الدفع الفعلي يجب أن يتم داخل المنصة وبحسب إتاحتها للحساب والبلد.
