# AI Agent Hub
Mobile-friendly PWA starter served by a small Node.js web service.

## Render
- Runtime: Node
- Build command: `npm install`
- Start command: `npm start`

API endpoints: `/api/health`, `/api/status`, `/api/activities`.
Set `TOTO_API_TOKEN` as a secret environment variable in Render before production use.
Social platforms are not connected in this starter; connect them only through official OAuth/API flows.
